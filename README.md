# SENSE-AI
Sense AI is a deep-learning-powered sentiment engine that moves beyond simple keyword matching. Built with TensorFlow and Keras, it analyzes the "vibe" of movie reviews to determine if a film is a "Peak" masterpiece or a "Flop" in real-time.
🔥 Key Features
Sequence-Aware Deep Learning: Uses LSTM (Long Short-Term Memory) layers to understand context and word order, accurately identifying sarcasm and complex opinions.

Vectorized Word Mapping: Leverages high-dimensional Word Embeddings to mathematically group similar concepts (e.g., "breathtaking" and "stunning").

Dynamic UI Experience: A high-end Streamlit interface featuring real-time "Aura Checks" and an auto-rotating live buzz feed of IMDb samples.

Dual-Engine Backend: Includes a robust fallback system (VADER Lexicon) to ensure the app stays "cracked" even if the neural network is offline.

🛠️ Tech Stack
Language: Python 3.13

Deep Learning: TensorFlow / Keras

NLP: NLTK, Tokenization, Sequence Padding

Frontend: Streamlit (Custom CSS Glassmorphism)

Data: Pandas & NumPy

🚀 Quick Start
Clone the repo: git clone https://github.com/yourusername/sense-ai.git

Run the App: streamlit run app.py
